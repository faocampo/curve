# Dashboard public reference

The archived dashboard capture has been withdrawn during disclosure cleanup.
The public design requirements are:

- Show a permission-scoped queue of decisions that need the signed-in user.
- Link each decision to its Initiative, relevant evidence and available action.
- Summarize Initiative progress using clearly defined, current counts.
- Keep personal work execution in the work-management views; Home adds
  cross-Initiative decisions and exceptions rather than duplicating task lists.
- Represent loading, no accessible work, stale data and failed retrieval
  separately. Never substitute illustrative metrics for live results.
- Use fictional actors, products and organizations in public design evidence.

See [experience blueprint](../../technical/curve-experience-blueprint.md)
(navigation, task flows and user-facing acceptance requirements).
