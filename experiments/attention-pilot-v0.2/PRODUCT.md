# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People reviewing project decisions and follow-ups across existing work.

## Product Purpose

A bounded synthetic development pilot for Curve. Help a reviewer understand
what needs attention, why it matters, and which existing source project owns it.

## Operating Context

This prototype explores attention review and existing-project references.
Existing project and task history stays source-owned. No real account is connected.

## Capabilities and Constraints

- Attention, Projects, Sources and local personal review actions.
- UI and read-only MCP share one durable synthetic local store.
- Existing projects appear through read-only bindings, with incomplete history visible.
- Personal handling and snoozing do not close source tasks or grant approvals.
- Source credentials, live adapters, imports and production are excluded.
- The proposed extension remains separate from existing Curve contracts.

## Brand Commitments

Inherit the Curve horizontal lockup, restrained light application shell, Curve
Indigo, Curve Ink and existing system sans typography from the incumbent product.

## Evidence on Hand

The source Curve product record and brand documentation define the visual system.
All pilot records and interactions use fictional demonstration data.

## Product Principles

1. A reason and source should explain each recommendation.
2. Personal state is distinct from source state and governed lifecycle authority.
3. Unknown, stale, inaccessible and partial information must stay explicit.
4. Review existing work without rewriting its history.

## Accessibility & Inclusion

Responsive semantic HTML, keyboard controls, visible focus, readable contrast and
screen-reader announcements. Formal accessibility certification remains unverified.

## Prototype assumptions

The portable dependency-free stack and split list/detail composition are development
choices for this isolated candidate, not production architecture commitments.
