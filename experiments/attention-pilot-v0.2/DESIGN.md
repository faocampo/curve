# Curve attention pilot design

Established-world extension, Operate mode. Preserve the Curve horizontal logo,
light work canvas, near-white navigation and Indigo selected/action states.

Attention uses a compact scan list and an adjacent evidence/details pane. Projects
use source task rows and an explicit history timeline. Sources use a plain coverage
list. Controls name personal effects; implementation and connection limits are
visible without dominating the main task.

System sans, 14–16 px body/control text, fixed 30 px page titles, muted slate copy,
1 px borders, 8 px control radii and 16–32 px section gaps. Red/amber indicate
attention and incomplete evidence with accompanying words. Avoid decorative cards,
metric tiles, fabricated charts, gradients or an alternate brand.

At 1000 px the detail pane stacks; at 700 px navigation becomes a horizontal row.
List buttons, links, search, filters and native details controls are keyboard usable.
Focus returns to the corresponding control after re-rendering when it remains visible.
Demo disclosure state survives refresh and scenario actions, including keyboard use.
